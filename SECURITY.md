# Security policy

## Supported versions

No version has been released yet, so no version is supported at the moment. This section will list the supported versions once the first release is tagged.

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it through GitHub private vulnerability reporting: open the Security tab of the repository at https://github.com/Matse2005/composer-vault and choose "Report a vulnerability".

Please include:

- A description of the problem and its impact.
- The steps to reproduce it, or a proof of concept.
- The affected version or commit.
- Any suggested fix, if you have one.

Do not include real credentials, tokens or keys in the report.

## What to expect

I acknowledge every report within 7 days. After that I keep you informed about the assessment and the fix, and I agree a disclosure date with you before anything is made public.
